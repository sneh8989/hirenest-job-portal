2. STEP-BY-STEP PROJECT EXECUTION
================================================================================

METHOD A: ONE-CLICK AUTOMATION SCRIPTS (RECOMMENDED)
----------------------------------------------------
Step 1: Open PowerShell at project root (D:\Job-Portal)
Step 2: Initialize dependencies and seed the database:
        .\scripts\setup-windows.ps1
        (This creates backend\venv, installs pip requirements, installs npm
         packages, and seeds realistic users, jobs, applications, and logs).

Step 3: In Terminal 1, start the FastAPI Backend Server:
        .\scripts\run-backend.ps1
        -> Backend runs on: http://127.0.0.1:8000
        -> Swagger API Docs: http://127.0.0.1:8000/docs

Step 4: Open a second PowerShell terminal in D:\Job-Portal, and start the Frontend:
        .\scripts\run-frontend.ps1
        -> Frontend web app runs on: http://127.0.0.1:5173

Step 5: Open your web browser and navigate to:
        http://127.0.0.1:5173


METHOD B: MANUAL STEP-BY-STEP COMMANDS
--------------------------------------
If you prefer running commands manually without PowerShell scripts:

--- BACKEND EXECUTION ---
1. Open PowerShell and navigate to backend directory:
   cd D:\Job-Portal\backend

2. Create virtual environment (if not already created):
   python -m venv venv

3. Activate virtual environment:
   .\venv\Scripts\Activate.ps1

4. Install backend dependencies:
   pip install -r requirements.txt

5. Initialize and populate database with seed data:
   python -m app.data.seed_data

6. Start FastAPI server with live reload:
   python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

--- FRONTEND EXECUTION ---
1. Open a new PowerShell window and navigate to frontend directory:
   cd D:\Job-Portal\frontend

2. Install npm packages:
   npm install

3. Start Vite dev server:
   npm run dev -- --host 127.0.0.1 --port 5173

4. Open your browser at:
   http://127.0.0.1:5173

7. TROUBLESHOOTING & WINDOWS COMMON ISSUES
================================================================================

Issue 1: "[WinError 10013] An attempt was made to access a socket in a way forbidden by its access permissions"
Cause: Port 8000 is already in use by another running uvicorn process.
Solution:
In PowerShell, check what is using port 8000:
   netstat -ano | findstr :8000
Kill the process using its PID (e.g. PID 16120):
   taskkill /F /PID 16120
Then re-run: .\scripts\run-backend.ps1

Issue 2: "Port 5173 is in use, trying another one... http://127.0.0.1:5174/"
Cause: Port 5173 is already running another Vite instance.
Solution:
Kill existing node processes or find PID:
   netstat -ano | findstr :5173
   taskkill /F /PID <PID>
Then re-run: .\scripts\run-frontend.ps1

Issue 3: "Execution of scripts is disabled on this system"
Cause: PowerShell script execution policy.
Solution:
Run once in your PowerShell terminal:
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Issue 4: Need to completely reset and wipe the database:
Solution:
Simply run:
   .\scripts\seed-data.ps1
This drops all existing SQLite tables, recreates the schema, and reseeds fresh demo data.
